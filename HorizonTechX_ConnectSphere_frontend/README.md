# ConnectSphere - Frontend

This is the React 19 + Vite frontend client for ConnectSphere, styled with Tailwind CSS and Lucide icons.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment (.env)
# VITE_API_URL=http://localhost:5000/api
# VITE_SOCKET_URL=http://localhost:5000

# 3. Start development server
npm run dev
```

For full instructions, architecture details, and the 2-user real-time test checklist, see the main [README.md](../README.md).
