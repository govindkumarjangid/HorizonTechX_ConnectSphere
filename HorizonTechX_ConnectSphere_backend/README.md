# ConnectSphere - Backend

Express.js + MongoDB + Socket.IO backend for ConnectSphere.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment (.env)
# PORT=5000
# MONGODB_URI=mongodb+srv://...
# JWT_SECRET=...
# CLIENT_URL=http://localhost:5173

# 3. Start development server
npm run dev
```

For full instructions, architecture details, and the 2-user real-time test checklist, see the main [README.md](../README.md).
